# Palette source photos

One row per file in this directory. Every file is a Wikimedia Commons copy no wider than 1920 px: the Commons thumbnail at 1920 px where the original is wider, the original where it is not. Only files whose Commons metadata (extmetadata `LicenseShortName` and `LicenseUrl`, read through the Commons API on 2026-11-07) names CC BY, CC BY-SA, CC0 or public domain are here. Recheck a file's licence on its Commons page before reusing it.

Author is the Commons `Artist` field as the file page prints it, with any trailing full stop. Credit is the Commons `Credit` field. All files were fetched on 2026-11-07 from Wikimedia Commons only.

## Licence notes

- `dome.jpg` (Kok Leng Yeo), `allegory-of-justice.jpg` (Scott Anderson) and the other Flickr-origin files carry the licence the Commons file page states. This run did not open the Flickr pages, so the Flickr side is not rechecked.
- `front-cephoto.jpg` names its author as `CEphoto, Uwe Aranas`, as in the hansard repo's SOURCES.md for another file of his.
- CC BY-SA 3.0 and 4.0 files need attribution and share-alike if the photo itself is redistributed; a colour value read from it is not the photo.
